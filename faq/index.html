Using YUNA & AI models

Does YUNA need an internet connection?

It depends on how you use it. Local chat with an already-downloaded Ollama model can work offline. Internet is needed for model downloads, web search and cloud AI providers. When you use a cloud provider, your prompts are sent to that provider. YUNA does not add its own telemetry.

Can I use my own OpenAI, Claude or Gemini API key?

Yes. YUNA supports OpenAI, Anthropic, Google Gemini, DeepSeek, Groq and compatible endpoints. Add your own API configuration in settings. Provider usage fees are separate from the YUNA license.

Does YUNA run without a dedicated GPU?

Yes, a dedicated GPU is optional. However, local AI performance depends on your CPU, available RAM, graphics hardware and the model size. A model that is too large for your system may run very slowly or fail to load.

See the system requirements and AI Models Guide.

Can I change YUNA's personality?

Yes. You can edit the system prompt, adjust how a character responds and create separate characters with their own personalities.

Can I import my own Live2D character?

YUNA supports compatible Live2D models. Check the app's model import guidance and make sure your model files meet the supported format and size limits.

Compatibility & setup

Which operating systems are supported?

The current release supports Windows 10 and Windows 11. Mac and Linux are not available in the current release.

How much RAM do I need?

8 GB is the published minimum and 16 GB is recommended. Your chosen local AI model may need more memory. Read the full requirements before downloading large models.

Where can I download YUNA?

Get the license through Ko-fi, or visit the GitHub Releases page for the available download.

Purchases & licenses

What is the refund policy?

Due to the digital nature of the product, support-first resolution is offered. If YUNA doesn't work on your machine and support cannot resolve the issue, you may request a refund within 7 days of purchase, minus any applicable transfer fees or taxes.

How do I transfer my license to a new PC?

Contact support through Discord or email with your license key and proof of purchase. The old device can be deactivated and the new device activated, free of charge.

Do cloud API costs come with the YUNA license?

No. If you connect a cloud provider, you use your own API key and are responsible for any fees charged by that provider. Local Ollama models do not have per-request API fees.
