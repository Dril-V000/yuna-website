# What's new in YUNA v1.2

YUNA v1.2 is our biggest update yet. Here's everything that changed.

## Highlights

| Feature | Status |
|---|---|
| Custom AI model selection | ✅ New |
| MAJO character | ✅ New |
| Custom Live2D uploads | ✅ New |
| Premium black theme | ✅ New |
| Better multi-character memory | 🔧 Improved |

## 1. Choose your AI model

In v1.2 you can pick the model that fits your machine and your mood — local with Ollama or via your own API key.

## 2. Meet MAJO

A new companion joins the family. Mysterious, playful, and full of surprises.

> **Tip:** Existing users get all v1.2 features free — just update the app.

## 3. Upload your own Live2D model

Drag & drop a `.model3.json` folder with a thumbnail and YUNA will use it right away.

## 4. Memory improvements

Each character now keeps its own context, so conversations stay coherent even when you switch between them.

## 5. Fixed issues

- Edge TTS compatibility fixes
- Various UI glitches
- General performance improvements
