Before you install

Is your PC ready for YUNA?

YUNA is designed for Windows PCs, and a dedicated graphics card is not required to launch the app. The AI model you choose has a major impact on speed and memory use.

Download YUNAExplore AI model options

Minimum requirements

These are the published baseline specifications. Meeting them does not guarantee that every large local model will run smoothly.

⚙️

Processor

Intel Core i5 6th generation or AMD Ryzen 5 1600 / FX-8350 class.

🧠

Memory

8 GB RAM minimum. 16 GB is recommended, especially when running local AI models.

💾

Storage

Allow around 2–8 GB free, depending on the model you install. Some models may need more space.

🪟

Operating system

Windows 10 or Windows 11.

🎮

Graphics

A dedicated GPU is optional. Compatible graphics hardware can accelerate supported local models.

🌐

Internet

Needed for downloads, web search and cloud AI providers. Local chat with an already-downloaded model can work offline.

Recommended for a smoother local AI experience

ProcessorCore i7 / Ryzen 7 class or better
Memory16 GB RAM or more
GraphicsA compatible dedicated GPU can improve local model performance
StorageSSD with enough free space for your chosen models
Model size matters. A PC may run YUNA itself but struggle with a large language model. Choose a model that fits your available RAM/VRAM. See the AI Models Guide for the local and cloud options.

What about Mac or Linux?

YUNA currently targets Windows 10 and Windows 11. Mac and Linux support are not available in the current release.

For more setup and compatibility questions, visit the FAQ or ask in the Discord community.
